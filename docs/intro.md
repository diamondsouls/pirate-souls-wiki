# Welcome to the Pirate Souls Wiki

This wiki is a community knowledge base for everything in the game — items,
spells, NPCs, quests, classes, crafts, achievements. Most pages are
auto-generated from the live game database; the rest is written by players
like you.

## Main guide
The most comprehensive guide for the game can be found in this Steam Community post: **[Pirate Souls Is Tough, Let me Guide you!](https://steamcommunity.com/sharedfiles/filedetails/?id=2833627512)**

## Editing a page

1. Open any article.
2. Scroll to the bottom and click **Edit this page**.
3. Edit the markdown and enter your **in-game player name** if you want a chance to get the "Bronze Soul" role.
4. Submit. A moderator reviews the change and merges it.

You don't need a GitHub account, and you never have to use git.

## Writing a brand-new page

Want to cover something the auto-generated pages don't — a beginner's
guide, a lore essay, a boss strategy? Open the **[New page form](https://pirate-souls-wiki-edit.fly.dev/new)**
on the edit service, pick a title, and write your guide. Once a moderator
merges it, it'll appear under [Guides](/guides) automatically.

## Auto-generated vs player content

Every generated page has two parts:

```
<!-- AUTOGEN:START -->
... game stats, properties, images — refreshed from the database ...
<!-- AUTOGEN:END -->

## Notes
... your contributions live here ...
```

Edits **above** the `AUTOGEN:END` line will be overwritten on the next
sync. Add tips, lore, drop locations, builds, and walkthroughs **below**
that line. The "Notes" / "Walkthrough" sections are for you.

## Reporting a bug or wrong stat

Open an issue on the [public wiki repo](https://github.com/diamondsouls/pirate-souls-wiki/issues).
For game bugs (not wiki bugs), please contact the dev team in-game.
