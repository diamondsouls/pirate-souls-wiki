# Guides & Player Wiki

This section is the player-written part of the wiki. Pages here cover
topics that don't live in the game database — strategies, lore, beginner
tips, build guides, event walkthroughs.

## Want to add a page?

Click **+ New page** on any edit form, or visit the
[edit service](https://pirate-souls-wiki-edit.fly.dev/new) directly. Pick a title, write
your guide in markdown, and submit. A moderator will review and merge.
Your page will then appear in the sidebar on the left automatically.

You don't need a GitHub account, and you can submit anonymously if you
prefer.

Browse the sidebar on the left for everything currently published.
