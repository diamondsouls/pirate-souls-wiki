# Core Mechanics

## Stats

- **Agility** - Increases melee, melee weapon damage, and fighter/swordsmen skill damage.
- **Aim** - Increases ranged weapon damage, required for sniper skills.
- **Energy** - Increases maximum energy.
- **Health** - Increases maximum health.
- **Willpower** - Increases soul fruit based skills damage.

## Classes

- Fighter
- Swordsman
- Sniper
